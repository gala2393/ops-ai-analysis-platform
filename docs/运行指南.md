# 运行指南

## 环境要求

- Go 1.22 或更高版本
- Windows、Linux 或 macOS 均可编译
- 本地演示不需要 Docker，也不需要真实 Prometheus

## Windows 启动

在项目目录执行 `go build ./cmd/yunwei`，再执行 `yunwei.exe check-config -config config\app.yaml`。

第一个终端启动模拟 Prometheus：`yunwei.exe mock-prom -scenario config\mock-scenario.yaml -listen 127.0.0.1:18090`。

第二个终端启动 Web：`yunwei.exe serve -config config\app.yaml`。

浏览器打开 `http://127.0.0.1:18080/`。停止服务时在对应终端按 `Ctrl+C`。

## Linux/macOS 启动

编译命令为 `go build -o yunwei ./cmd/yunwei`，其余参数与 Windows 版本一致，只需将路径分隔符改为 `/`。

## 常见问题

`config/app.yaml` 默认访问本地 Mock Prometheus，因此页面里的主机是模拟数据。使用真实数据时，应改用 `config/app.real.yaml`，并先执行 `check-prom` 验证连接。

命令拼写必须是 `go build ./cmd/yunwei`，不是 `go bulid`。

端口被占用时，修改 `server.listen`、Mock Prometheus 的监听端口以及 `prometheus.url`，三处保持一致。

重新生成报告使用 `yunwei.exe inspect -config config\app.yaml -out reports`。报告位于 `reports/`，数据库位于 `data/yunwei.db`，两个目录均不会提交到 Git。

## 真实环境检查顺序

1. 确认 Prometheus 地址可访问。
2. 执行 `check-config` 检查 YAML 和环境变量。
3. 执行 `check-prom` 检查版本、targets 和健康状态。
4. 确认企业标签和巡检阈值后再替换默认配置。
5. 先执行一次 `inspect` 检查报告，再启动长期 `serve`。
