# 开发状态

## 已交付

- Go CLI、配置校验和 Prometheus 只读客户端。
- Mock Prometheus、180 台主机测试场景和异常注入。
- 主机发现、Exporter 归并和服务识别。
- 可配置巡检项、阈值判定、健康评分和问题分组。
- SQLite 运行记录和反馈存储。
- Markdown/HTML 报告生成。
- Web 总览、主机筛选、主机详情、趋势、报告列表和详情。
- 手动巡检、异步进度展示和反馈提交。
- 自动化测试覆盖核心包。

## 开发中

- LLM 客户端、脱敏、结构化输出和证据校验。
- Alertmanager webhook、事件聚合和告警报告。
- 真实通知渠道。
- 同比环比、容量预测、Runbook、日志和变更关联。

## 尚未承诺为生产能力

- 多租户权限、SSO/LDAP 和细粒度审计。
- 大规模高可用部署和 PostgreSQL 迁移。
- 真实企业巡检标准适配。
- AI 自动执行任何服务器命令。

## 推荐验收方式

启动 Mock Prometheus 后访问首页并执行一次手动巡检，确认总览中的主机数量、异常数量、问题分组和 PromQL 证据与生成报告一致。随后运行 `go test ./...` 检查回归。
